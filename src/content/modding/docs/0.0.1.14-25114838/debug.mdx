## Thresholds and channels

`EM.Logging.LogLevel` defines Verbose = 0, Debug = 1, Info = 2, Warning = 3, Error = 4, and Fatal = 5.
The logging code discards messages below a channel's minimum. Stock threshold 4 records errors and fatals;
lower it to 2 for informational output or 0 for the most verbose output.

The current configuration contains these thirteen fields:

- `minimumLogLevelForLua`, `minimumLogLevelForEngine`
- `minimumLogLevelForHostLua`, `minimumLogLevelForClientLua`
- `minimumLogLevelForHostLuaInterface`, `minimumLogLevelForClientLuaInterface`
- `minimumLogLevelForEngineInitialisation`, `minimumLogLevelForMovement`
- `minimumLogLevelForVFX`, `minimumLogLevelForAudio`
- `minimumLogLevelForUI`, `minimumLogLevelForNetwork`, `minimumLogLevelOther`

All thirteen are 4 in the inspected file. `minimumLogLevelForArtists` is absent.

## Where messages go

The current `LogManaged` configuration writes the general Lua channel to
`engine\game_logs\LogsForLuaDevs.txt`, opening it with append disabled during initialization.
Copy useful output before restarting.

Host/client Lua and interface channels have no separate file writer in that configuration. They are routed
through Unity logging and the in-game host/client log windows. The inspected configuration assigns no channel
writer to `LogsForArtists.txt`; an old file with that name is not evidence of an active destination.

These destinations were traced in code. Producing a diagnostic in each channel remains a runtime test.

## Confirmed launch parser

The inspected `CommandLineUtils` parser recognizes `-debugSettings=`, `-scenario=`, `-map=`,
`-autoplay=`, `-showFogOfWar=`, and `-showDebugUi=`. Boolean arguments expect true or false.
A custom debug filename is resolved beneath the game's Debug resource directory.

Other launch paths and the visible effects of those arguments were not exercised in this inspection.
Do not assume every flag documented for an older build still works.
