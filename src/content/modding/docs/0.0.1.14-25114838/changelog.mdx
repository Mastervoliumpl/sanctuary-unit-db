# Release notes and modding changes

<Lead>
  This page compares the reviewed build 25019767 documentation with inspection of build 25114838. It also
  summarizes the supplied developer announcement. Developer reports, static findings, and runtime results are
  identified separately.

## Developer announcement

[FoneE's Sanctuary update thread](https://discord.com/channels/781554164307591219/1543565008846323782/1545256895680352337)
begins with an announcement labelled **Version 118**, posted on September 4, 2026. The summary below uses a
contributor-supplied transcript spanning several messages; the link opens the first message and may require
Discord access. That announcement label has not been independently mapped to internal game version 0.0.1.14
or Steam build 25114838. Shared features alone do not establish the mapping.

The developers report automatic replays, a revised AI, core UI and settings changes, in-game chat, targeting
and audio improvements, and balance changes. For modders, the technical notes highlight Unity 6000, an updated
LuaJIT, a new logger and command system, client-disconnection information in Lua, instance parenting, and
visual rotators. They also report faster Lua execution and memory-bounded desync checks.

The announcement says replays require the recording engine version and may become unusable after updates.
It describes one-direction playback with Page Up/Page Down speed controls. Known issues include unfinished
lobby UI, units getting stuck inside buildings when starting projects, and box selection breaking after a
resolution change until restart. Those are developer reports, not results of this inspection.

## Replay compatibility includes the Lua hash

**Static finding.** `EM.Network.Replay.ReplayFile` writes `.sanreplay` files beneath
`Application.persistentDataPath/Replays`. The recorded game identity combines the application version with
the Lua hash. `EM.UI.ReplayListInterface` compares that identity with the current installation and disables
the selection button for a mismatch. `ReplayClientSockets` separately checks the replay format version.

This adds a modding detail to the developer's version warning: changing Lua can make a replay unavailable
through the replay list even when the Steam build has not changed. The inspected replay header does not
provide a complete manifest of templates, maps, assets, or installed mods. A matching identity is therefore
not proof that every relevant input matches. In particular, templates remain outside the Lua hash.

Keep a replay's build identity and test-file hashes with any bug report. Actual playback and the visible
mismatch behavior still need the [controlled runtime checks](./runtime-tests).

## Settings have a JSON persistence path

**Static finding.** `EM.GameUtils.UserSettings` loads and saves `userSettings.json` beneath
`Application.persistentDataPath`. Its data includes `uiScale` and `iconScale`, constrained to 0.5–1.75
when loaded. The interface applies this settings data through the settings UI.

The older registry-based UI-scale advice should not be treated as the current procedure. Use the settings
menu and verify persistence after a restart. This finding does not mean all PlayerPrefs keys disappeared;
the [connection and map keys](./playerprefs) are still present in managed code. Migration from an older
UI-scale value has not been traced.

## Command and disconnection paths to review

**Static finding.** The current `host/commands.lua` handles an engine disconnection command by updating the
lobby player list and sending a session log message. Other incoming commands go through the shared command
registry. The managed command queue also has an instance-parenting command path.

These paths help locate the features named in the announcement. They do not establish which old callbacks
were replaced, whether a mod's command format still works, or whether parenting supplies a complete transport
system. Recheck command-related hooks before porting them; no performance comparison was run here.

## Deprecations, breakage, and open checks

No complete API comparison or mod execution test was performed, so this page declares no API removals,
official deprecations, or tested mod breakages. The absent artist-log setting is a configuration difference,
not an inferred deprecation notice. An exact old-build assembly and annotation baseline would support a more
specific compatibility comparison.

The announcement's exact LuaJIT revision, performance gains, desync memory cap, and detailed balance changes
have not been independently measured here. The new findings are checked in code; follow the
[runtime test handoff](./runtime-tests) to turn them into observed behavior.
