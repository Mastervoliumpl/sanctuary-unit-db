# Modding the inspected playtest

<Lead>
  This snapshot describes game 0.0.1.14 on Unity 6000.3.22f1. It records Lua, template, asset, map, and
  logging findings from build 25114838. The earlier build remains available in the version selector.
</Lead>

<Callout title="Keep simulation tests coordinated" warning>
  A client with a different Lua hash is rejected before joining. Templates are outside that hash and can
  desynchronize a running simulation. Test changes offline first, then use identical files on every test
  machine.
</Callout>

## What changed in this inspection

The Lua tree contains 590 Lua files and 367 loose templates. The generated API files contain 442 client functions
and 253 host functions. The logging settings now cover thirteen channels through `EM.Logging`; the earlier
artist-log setting is absent from this build's configuration.

## Test a small change

The [runtime checks](./runtime-tests) start with replay recording and settings persistence, and include a
short template for reporting results.

Copy the original file, make one change, and run an offline test. Record the result and restore the file before
testing another change. Keep untested behavior separate from findings visible in the shipped files.

This is community research, not official documentation from Enhearten Media.
