# System and file layout

<Lead>
  The playtest is a 64-bit Unity Mono build. Its managed game code, LuaJIT scripts, Burst code, and game data
  are separate parts of the installation.
</Lead>

## Runtime stack

- `Sanctuary.exe` and `UnityPlayer.dll` run Unity 2022.3.62f3.
- `Trebuchet.dll` contains the main managed game and tool code.
- Unity Entities and Burst implement parts of the simulation and rendering.
- LuaJIT runs separate host and client script states.
