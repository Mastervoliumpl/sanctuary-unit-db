# Map files and included tools

<Lead>
  Steam build 25019767 contains 150 `.sanmap` files: 79 named maps and 71 generated `~FFA-*` and `~TEAM-*`
  maps. Those 71 prefixed maps are output from the shipped generator. The files begin with readable JSON
  metadata and the installation includes a separate map generator.
</Lead>

## Installed content

<Paths>
  <code>engine\Sanctuary_Data\Maps&#92;</code>

Start from a copied map. Change one field, use a distinct file name, and verify that the game lists it as a
separate map. A complete `.sanmap` schema has not been documented.

The readable `.sanmap` JSON header is self-describing and includes `fileVersion`, `mapVersion`, `width`,
`heightmapResolution`, and `waterLevel` before the remaining map data.

## Compiled editor code

`Trebuchet.dll` contains an `EM.MapEditor` namespace for map selection, terrain, textures, props, decals,
symmetry, lighting, water, undo history, and save or export UI. `EM.Map.MapManager` also contains a map-editor
world and an `IsMapEditor` state.

<Callout title="The editor launch path is not confirmed" warning>
  Code can remain in a Unity build when its scene or UI entry point is absent. The shipped scenes, resources,
  startup condition, and generator output still need an end-to-end test.
</Callout>
