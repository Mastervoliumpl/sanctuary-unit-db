# Debug settings, logs, and launch flags

<Lead>
  The player build loads a JSON configuration for logging, Lua, rendering, camera behavior, pathfinding,
  collision, internal visualizations, and quick launch.
</Lead>

## Configuration file

<Paths>
  <code>engine\Sanctuary_Data\Resources\Editor\Debug\Build.json</code>
</Paths>

This snapshot enables the Lua sandbox, desync asserter, and pathfinding. It disables the file watcher and quick
launch. Copy the file before editing it because Steam can replace installation files.

## Lua and artist logs

<Paths>
  <code>engine\game_logs\LogsForLuaDevs.txt</code>
  <code>engine\game_logs\LogsForArtists.txt</code>
</Paths>

Both files are truncated when the game launches. Copy useful output before restarting. Six `Build.json` fields
control the minimum logged level. The stock value is `4` (Error) for each field, so errors and fatal messages
are recorded. A healthy session can leave the logs empty because no messages reached that threshold.

The levels are Verbose (`0`), Debug (`1`), Info (`2`), Warning (`3`), Error (`4`), and Fatal (`5`). Lower the
minimum level to see more output: use `2` for informational messages such as `Log()`, or `0` for the most
verbose output. Restore the stock values when finished debugging.
